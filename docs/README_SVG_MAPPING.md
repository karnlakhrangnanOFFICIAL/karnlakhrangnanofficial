# คู่มือการจับคู่ ไฟล์ SVG ให้ตรงกับ Code ที่ใช้แสดงผลต่างๆ

ไฟล์ SVG ทั้งหมดถูกจัดเก็บไว้ที่ \`databases/logo/svg/\`

| ไฟล์ SVG | ความหมาย/เหตุการณ์ | ตัวอย่างการใช้งานใน Code HTML |
| :--- | :--- | :--- |
| \`calendar-news.svg\` | ไอคอนปฏิทินข่าว | \`<img src="databases/logo/svg/calendar-news.svg" alt="Date" class="...">\` |
| \`goal.svg\` | ทำประตูได้ (Goal) | ใช้แสดงผลข้างชื่อนักเตะที่ทำประตูได้ |
| \`assist.svg\` | ส่งบอลให้ทำประตู (Assist) | ใช้แสดงผลข้างชื่อนักเตะที่ส่งบอล |
| \`own-goal.svg\` | ทำเข้าประตูตัวเอง (Own Goal) | ใช้แสดงผลข้างชื่อนักเตะที่ทำเข้าประตูตัวเอง |
| \`yellow_card.svg\` | ใบเหลือง (Yellow Card) | ใช้แสดงผลข้างชื่อนักเตะที่ได้รับใบเหลือง |
| \`second_yellow_card-2x.svg\` | ใบเหลืองที่ 2 (Second Yellow Card) | ใช้แสดงผลข้างชื่อนักเตะที่ได้รับใบเหลืองที่ 2 |
| \`red_card.svg\` | ใบแดง (Red Card) | ใช้แสดงผลข้างชื่อนักเตะที่ได้รับใบแดง |
| \`substitution_in.svg\` | เปลี่ยนตัวเข้า (Substitution In) | ใช้แสดงผลในเหตุการณ์เปลี่ยนตัวผู้เล่น (คนเข้า) |
| \`substitution_out.svg\` | เปลี่ยนตัวออก (Substitution Out) | ใช้แสดงผลในเหตุการณ์เปลี่ยนตัวผู้เล่น (คนออก) |
| \`injury.svg\` | อาการบาดเจ็บ (Injury) | ใช้แสดงผลข้างชื่อนักเตะที่มีอาการบาดเจ็บ |
| \`var.svg\` | การตัดสินด้วย VAR (VAR) | ใช้แสดงเหตุการณ์ที่มีการใช้ VAR |
| \`yyyy.svg\` | (ไม่ระบุ/รอการอัปเดต) | |
| \`stadium.svg\` | สนามแข่งขัน (Stadium) | ใช้แสดงผลคู่กับชื่อสนาม |
| \`football-team-bench-home.svg\` | ม้านั่งสำรองทีมเหย้า | |
| \`football-team-bench-away.svg\` | ม้านั่งสำรองทีมเยือน | |
| \`manager-home.svg\` | ผู้จัดการทีมเหย้า | |
| \`manager-away.svg\` | ผู้จัดการทีมเยือน | |
| \`list_line-up_home.svg\` | รายชื่อผู้เล่นตัวจริงทีมเหย้า | |
| \`list_line-up_away.svg\` | รายชื่อผู้เล่นตัวจริงทีมเยือน | |
