# การตั้งค่าเทมเพลตข้อมูลนักเตะ (Player Profile)
เราได้ออกแบบโครงสร้างข้อมูลสำหรับโปรไฟล์นักเตะ 1 คน ที่ครอบคลุมทั้งข้อมูลส่วนตัว สถิติ และโซเชียลมีเดีย ซึ่งคุณสามารถเพิ่มคอลัมน์เหล่านี้ลงใน **Google Sheets** ที่ใช้อยู่ปัจจุบันได้เลย

โครงสร้างฟิลด์ข้อมูลที่ควรรองรับมีดังนี้:
1. `id` - รหัสนักเตะ (สำคัญมาก ไว้สำหรับอ้างอิง)
2. `name` - ชื่อนักเตะ
3. `number` - หมายเลขเสื้อ
4. `position` - ตำแหน่ง (Goalkeeper, Defender, Midfielder, Forward)
5. `nationality` - สัญชาติ
6. `image` - รูปภาพ (URL หรือพาทไฟล์)
7. `height` - ส่วนสูง (cm)
8. `foot` - เท้าข้างที่ถนัด (Left/Right)
9. `date_of_birth` - วันเกิด (YYYY-MM-DD)
10. `age` - อายุ
11. `joined` - วันที่เข้าร่วมทีม
12. `signed_from` - สโมสรเดิม
13. `market_value` - มูลค่าตลาด
14. `appearances` - จำนวนนัดที่ลงเล่น
15. `goals` - ประตู
16. `assists` - แอสซิสต์
17. `bio` *(คอลัมน์ใหม่)* - ประวัติหรือคำบรรยายสั้นๆ
18. `instagram` *(คอลัมน์ใหม่)* - ชื่อผู้ใช้ IG หรือ URL
19. `twitter` *(คอลัมน์ใหม่)* - ชื่อผู้ใช้ Twitter หรือ URL

ระบบหน้า `player-profile.html` ได้ถูกเขียนให้สามารถรับข้อมูลเหล่านี้จาก JSON/API ปัจจุบันและแสดงผลในเทมเพลตได้ทันที
